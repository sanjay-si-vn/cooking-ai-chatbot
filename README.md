# 🍳 Cooking AI Chatbot

An AI-powered chatbot that helps users with cooking recipes, ingredient suggestions, and step-by-step guidance.

---

## 🚀 Features

* AI-based cooking assistant
* Recipe suggestions based on ingredients
* Step-by-step cooking instructions
* Interactive chatbot UI
* Fast and responsive frontend

---

## 🛠️ Tech Stack

**Frontend:**

* HTML
* CSS
* JavaScript

**Backend:**

* Python
* FastAPI (or Flask — update if needed)

**AI Integration:**

* Groq API (LLM)

## ⚙️ Setup Instructions

### 1. Clone the repository

```
git clone https://github.com/sanjay-si-vn/cooking-ai-chatbot.git
cd cooking-ai-chatbot
```

---

### 2. Install backend dependencies

```
pip install -r requirements.txt
```

---

### 3. Setup environment variables

Create a `.env` file inside `backend/`:

```
GROQ_API_KEY=your_api_key_here
```

---

### 4. Run backend server

```
python main.py
```

---

### 5. Open frontend

Open `index.html` in your browser.
